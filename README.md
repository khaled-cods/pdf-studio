# PDF Studio

قارئ ومحرر PDF بالعربي والإنجليزي، بيشتغل من غير نت على الموبايل (أندرويد) وكالي/لينكس والمتصفح.

PDF reader and editor (Arabic / English) that works fully offline on Android, Linux and the web.

## التحميل
آخر نسخة دايماً في صفحة **[Releases](../../releases/latest)**:
- **أندرويد:** `PDF-Studio.apk`
- **كالي / لينكس:** ملف `.deb` (`sudo apt install ./PDF-Studio-*.deb`) أو `.AppImage`

## المميزات
- قراءة بجودة عالية، بحث في النص، ونسخ الكلام
- كتابة نص، تظليل، رسم، مربعات، أسهم، إخفاء، صور وتوقيع
- تكرار أي تعديل على كل الصفحات أو صفحات معينة في نفس المكان
- دمج، تقسيم، ترتيب وتدوير وحذف الصفحات
- علامة مائية وترقيم الصفحات
- صور إلى PDF، PDF إلى صور، وضغط الملفات
- الملفات ما بتطلعش من جهازك

## إزاي بيتبني
كل مرة يتغيّر فيها المشروع، GitHub Actions بيبني ملف APK وملفات لينكس لوحده ويحطهم في صفحة Releases.
